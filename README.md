# 교수님 퇴임 기념식 초청장

React 19, Vite, TypeScript, SCSS로 만든 모바일 우선 행사 초청장입니다. 기본 문구는 격식 있는 교수님 퇴임 기념식에 맞춰져 있으며, 행사용 데이터와 사진은 프로젝트 내부에서 설정합니다.

## 시작하기

```bash
npm install
npm run dev
```

카카오톡 공유 기능을 사용할 때는 `.env.example`을 복사해 `.env`를 만들고 `VITE_KAKAO_SDK_JS_KEY`를 설정합니다. 카카오 공유를 설정하지 않아도 초청장 자체는 동작합니다.

## 행사 정보 수정

`src/const.ts`에서 다음 정보를 편집합니다.

- 교수님 성함과 소속
- 행사 일시 (`YYYY-MM-DD HH:mm`, 한국 시간)
- 행사 장소, 주소, 지도 검색어, 교통 안내
- 행사 순서와 다과 안내
- 초청 문구에 표시할 주최자 서명

일시·장소 등 아직 정해지지 않은 항목은 빈 값으로 두면 안내 문구와 장소 링크를 숨기거나 준비 중으로 표시합니다. 계좌 정보, 결혼식 참석 응답, 방명록과 서버 연동은 포함하지 않습니다.

## 사진 추가

교수님 표지 사진 또는 강의·연구·학교 생활 사진을 `src/images/`에 추가하고 `src/images/index.ts`에서 불러옵니다. 표지 사진은 `Cover`에, 갤러리 사진은 `GALLERY_IMAGES`에 연결합니다. 큰 사진은 모바일 로딩을 위해 가로 약 1000px 수준으로 줄이고 WebP 또는 압축된 JPEG를 권장합니다.

공유 미리보기 이미지는 `public/preview_image.svg`입니다. 실제 행사 사진이나 학교 디자인으로 바꾸려면 SVG를 편집하거나, 이미지 형식과 `index.html`의 `og:image` 경로를 함께 바꾸세요.

## 빌드와 배포

```bash
npm run build
npm run preview
```

Vite는 `build/`에 정적 파일을 생성합니다. 배포 주소가 저장소 하위 경로라면 `package.json`의 `homepage`를 실제 주소로 설정하세요. 빌드 시 HTML 제목·설명과 웹 앱 매니페스트에는 `src/const.ts`의 행사 정보가 반영됩니다.
